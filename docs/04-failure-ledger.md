# 避坑账本：带 GC 的经验库

> 所有 Agent 用户都痛"同一个坑踩三次"，但极少有人把它工程化。更少有人处理它带来的副作用：**经验库自己会变成上下文炸弹**。

---

## 一、问题

把踩过的坑记下来，直觉上是对的。但天真做法会走向两个失败：

| 失败模式 | 现象 |
| :--- | :--- |
| **不记** | 同一个坑反复踩，每次都要重新诊断 |
| **记太多** | 账本膨胀到 5000 token，塞进 system prompt 就崩 |

第二个更隐蔽——多数人是在账本炸了之后才发现。

---

## 二、四道闸门

这套做法的核心不是"记什么"，而是**"什么不该记"** + **"记满了怎么办"**。

### 闸门 1：三不录原则

**不录**的三种情况：

1. **单次偶发** —— 只发生一次的，不是规律
2. **非共性逻辑** —— 只在这个项目成立的，不写进全局
3. **已有补丁能覆盖的** —— 不新增，去扩充那条补丁

> "什么不该记"比"该记什么"难得多。这三条是账本不爆炸的根本。

### 闸门 2：12 行微卡

单条补丁不超过 **12 行**。固定三段式：

```markdown
### 补丁 007【防孤岛文件】

- **触发背景**：新建文件后没人引用，逐渐变成数字废纸
- **致命陷阱**：手工维护索引必死，人懒、Agent 也会忘
- **刚性规则**：新建文件必须在同一轮完成五步闭环，并跑校验器
  ```bash
  python tools/verify_workspace_links.py
  ```
```

### 闸门 3：300 行熔断

全局账本**硬性控制在 300 行内**。接近上限时，合并同类项，而不是继续追加。

> 这是给经验库装的 GC。没有熔断的账本，最后一定会变成没人读的墓碑。

### 闸门 4：两级分流

- **全局通用坑** → 入全局账本
- **领域专属坑** → 下沉到该领域目录下的专项文件

通用知识上浮，领域知识下沉。任何多领域 Agent 都适用。

## 三、场景速查表（Index-First）

即使账本只有 300 行，逐行读仍是浪费。所以正文前先放一张速查表：

| 场景分类 | 覆盖补丁 | 核心防御收益 |
| :--- | :--- | :--- |
| 排版与渲染 | 001, 016 | 公式坍塌、表格错乱 |
| 交互纪律 | 002, 004, 018 | 人设废话、散文反问、谄媚 |
| 文件治理 | 007, 019 | 孤岛文件、根目录污染 |
| 环境与命令 | 009, 011 | 路径空格、括号断链 |
| 经验沉淀 | 010 | 账本膨胀 |

查账本从 O(n) 变成 O(1)。

## 四、补丁的通用性分级

不是所有坑都值得进全局账本。实践中大致分三档：

| 档位 | 特征 | 处置 |
| :--- | :--- | :--- |
| ★★★★★ | 与领域完全无关（如"决策点必须用结构化提问"） | 直接进全局 |
| ★★★☆☆ | 半通用（如"学术插图规范"） | 进全局，但举例去掉领域细节 |
| ★★☆☆☆ | 强绑定本机环境（如"本机没装 Pandoc"） | **不进全局**，或写进项目 README |

---

## 五、可迁移的补丁清单

以下是经过验证、与具体领域解耦的通用补丁主题。可以按需取用：

| 主题 | 一句话规则 |
| :--- | :--- |
| 结构化提问 | 关键分叉点禁止散文发问，必须给 2～4 个互斥选项 |
| 防孤岛文件 | 新建文件必须完成五步闭环并跑校验器 |
| 根目录防污染 | 产出物就地归档，禁止往根目录抛洒 |
| 双轨交付 | 对话流只做推导，正式交付物后台落盘并卡片交付 |
| 反谄媚 | 禁用浮夸修辞，有新想法按正常探讨对待 |
| 内部状态不外溢 | 不要把 Agent 的调度过程写成 UI 文案 |
| 全量归档 | 外部权威文件先无损转存再加工，禁止用完就删 |
| 会话隔离 | "用"和"改"拆成两种会话，防止角色分裂 |
| 渲染防坍塌 | 表格禁用 LaTeX 宏；跨列数据重复填值 |
| 语音容错 | 同音错字静默重构，不挑刺、不回音壁 |

## 六、常见错误

| 错误 | 后果 | 修正 |
| :--- | :--- | :--- |
| 没有三不录 | 账本被偶发问题塞满 | 先立闸门再记账 |
| 补丁写成长文 | 单条吃掉几十行 | 12 行三段式 |
| 没有熔断 | 300 行后继续涨 | 定期合并同类项 |
| 领域坑写进全局 | 污染全局上下文 | 两级分流 |
| 只记不删 | 过时补丁仍在生效 | 定期复审，失效的删掉 |
