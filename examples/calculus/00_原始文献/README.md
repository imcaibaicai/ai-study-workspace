# 原始文献索引（示例）

> 本目录用于存放**全量无损转存**后的外部权威文件（大纲、讲义、官方说明等）。
> 示例仓库中此目录为空，只保留索引结构。

---

## 一、为什么需要这个目录

外部权威文件有两个特征：

1. **不可重建**——丢了就没了，模型无法"回忆"出原文
2. **不该被消耗**——只用一次就删，下次会话只能靠模型脑补

所以纪律是：**收到外部文件，第 0 步先全量转存归档，再谈提炼。**

---

## 二、归档规范

| 项目 | 要求 |
| :--- | :--- |
| 格式 | 统一转为 Markdown（`.md`），保留原始结构 |
| 命名 | 保留原文件名 + 必要的版本标识 |
| 位置 | 本目录下，不放别处 |
| 索引 | 每份文件都要在本页登记一行 |

## 三、为什么示例仓库里是空的

本仓库是方法论示范，**刻意不收录任何教材、讲义、真题或官方文件**：

- 这些内容有版权，不宜公开分发
- 它们与具体机构绑定，会削弱示例的通用性
- 方法论的价值在结构，不在具体材料
