# 考点01 极限与连续

> **考点卡不是抄书。** 它的价值在"哪里容易错"，不在"定义是什么"——定义书上都有。

---

## 一、核心直觉（先建立图像，再上符号）

### 极限：不是"到达"，是"任意逼近"

初学者最容易的误解：把 $\lim_{x \to a} f(x) = L$ 理解成"$f(a) = L$"。

**两者的区别是整个考点的根**：

| | 含义 | 是否要求 $f(a)$ 存在 |
| :--- | :--- | :--- |
| $f(a) = L$ | 在点 $a$ 处的**取值** | 是 |
| $\lim_{x \to a} f(x) = L$ | $x$ **无限靠近** $a$ 时 $f$ 的趋势 | **否** |

所以极限讨论的是**去心邻域**，与 $a$ 点本身的值无关。

### 连续：三件事同时成立

$f$ 在 $a$ 处连续 $\iff$

1. $f(a)$ 有定义
2. $\lim_{x \to a} f(x)$ 存在
3. $\lim_{x \to a} f(x) = f(a)$

**这三条任何一条断掉，就是间断。** 断在哪一条，决定了间断的类型。

---

## 二、前提与边界条件（最容易漏的地方）

| 结论 | 前提 | 漏掉的后果 |
| :--- | :--- | :--- |
| 极限四则运算可拆 | **两个极限都存在** | 拆出 $\infty - \infty$ 得到荒谬结果 |
| 复合函数极限可代入 | 外层函数在对应点**连续** | 直接代入得错误值 |
| 洛必达法则可用 | 必须是 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型，且导数比极限存在 | 乱用得到循环或错误结论 |

> **纪律**：写任何一步之前，先问"这一步的前提成立吗"。步骤分很大程度来自这里。

---

## 三、易混淆辨析

| 概念 A | 概念 B | 关键区别 |
| :--- | :--- | :--- |
| 极限存在 | 函数在该点有定义 | 极限看**去心邻域**，不看该点 |
| 左极限存在 | 极限存在 | 必须**左右都存在且相等** |
| 可去间断 | 跳跃间断 | 前者左右极限**相等**但≠函数值；后者左右极限**不等** |
| 无穷间断 | 振荡间断 | 前者趋于无穷；后者在有限范围内**反复震荡无极限** |

### 间断点分类速判

```text
先算左右极限
   ├── 左右都不存在（振荡） ──────────→ 振荡间断（第二类）
   ├── 至少一侧为 ∞ ─────────────────→ 无穷间断（第二类）
   └── 左右都存在
         ├── 相等但 ≠ f(a) ───────────→ 可去间断（第一类）
         └── 不相等 ──────────────────→ 跳跃间断（第一类）
```

---

## 四、常见错误

| 错误 | 为什么会犯 | 正确做法 |
| :--- | :--- | :--- |
| 分段点直接代入 | 忘了分段点两侧表达式不同 | 先算左右极限，再判断是否相等 |
| 默认极限存在 | 没验证就拆四则运算 | 先证存在，再运算 |
| 把 $f(a)$ 当极限 | 混淆取值与趋势 | 极限看去心邻域 |
| 间断分类只看图 | 图上看不出"该点有没有定义" | 必须回代验证 $f(a)$ |

## 五、自检问题

学完这一卡，应该能立刻回答：

1. 为什么极限的定义里要写 $0 < |x - a| < \delta$ 而不是 $|x - a| < \delta$？
2. 一个函数在 $a$ 点有极限但没定义，它在 $a$ 点连续吗？属于哪类间断？
3. 左右极限都存在但不相等，属于第几类间断？为什么？
