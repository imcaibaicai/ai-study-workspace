## 二、目录结构

```text
examples/calculus/
├── README.md                          # 本文件：领域总路由
├── 状态.json                          # 该领域的状态中枢片段
├── 00_原始文献/
│   └── README.md                      # 原始文件索引（示例为空）
├── 01_计划/
│   └── 全景方案.md                     # 顶层纲领：阶段、目标、掌握度地图
├── 02_核心考点/
│   └── 考点01_极限与连续.md             # 微观机理：图像、前提、易混淆
└── 03_题型模板/
    └── 模板01_极限计算流水线.md         # 落地：步骤分打法
```

### 三层单向辐射

```text
01_计划  ──引向──>  02_核心考点  ──引向──>  03_题型模板
   ↑                                          │
   └──────────── 文尾回指（更新状态）───────────┘
```

**纪律**：上层引向下层，下层文尾回指状态中枢。不要反向——考点卡不该去改计划文件。

## 三、刻意省略了什么

这是开源示例，所以以下内容**全部移除**：

| 移除项 | 原因 |
| :--- | :--- |
| 具体教材版本、页码、ISBN | 指向特定出版物，无必要且涉版权 |
| 真实课程编号与学分 | 是特定院校的编码，可反推机构 |
| 考核权重百分比 | 特定院校特定学期的制度 |
| 教师姓名、教室、课表 | 直接可定位到个人与机构 |
| 真实作业题与答案 | 教材/习题集版权 |
| 个人学习进度与薄弱点 | 隐私 |

保留的只有**结构与方法**：目录怎么排、文件怎么写、网格怎么串、状态怎么记。
