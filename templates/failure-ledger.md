# 经验沉淀账本（避坑账本.md）

> **总则**：账本只记**共性规律**，不记一次性问题。
> **防膨胀**：单条 ≤ 12 行；全局 ≤ 300 行；接近上限时**合并同类项**，而不是继续追加。
> **两级分流**：全局通用坑入本账本，领域专属坑下沉到对应领域目录。

## 二、已激活刚性规则明细（超密微卡）

### 补丁 001【结构化提问：关键分叉禁止散文发问】

- **触发背景**：遇到路线选择、阶段推进、偏好取舍等分叉点
- **致命陷阱**：散文式"你觉得怎么样？"让用户无法快速作答，Agent 趁机替用户做主
- **刚性规则**：必须给 **2～4 个互斥且具体**的选项，推荐项置首并标注「(推荐)」，每项附一句影响说明

### 补丁 002【防孤岛文件：五步闭环 + 校验器】

- **触发背景**：任何新建 Markdown 文件的操作
- **致命陷阱**：手工维护索引必死——人懒、Agent 也会忘，新文件逐渐变成数字废纸
- **刚性规则**：同一轮内完成五步（Frontmatter → 文尾网格 → 父级登记 → 上游回填 → 跑校验），并执行：
  ```bash
  python tools/verify_workspace_links.py
  ```

### 补丁 003【根目录防污染：产出物就地归档】

- **触发背景**：生成图片、脚本、报告等产出物
- **致命陷阱**：往根目录抛洒零散文件，破坏 L0 入口的整洁与可发现性
- **刚性规则**：成图入对应 `images/`；专用脚本入对应包内 `scripts/`（路径用 `__file__` 动态绑定）；过程切片入 `过程性文件/` 并登记索引

### 补丁 004【双轨交付：对话流与实体交付物解耦】

- **触发背景**：涉及正式报告、复杂表格、需要打印的交付物
- **致命陷阱**：在聊天框里勉强还原纸质长排版，必然坍塌
- **刚性规则**：对话流只做推导 + 轻量 GFM 表格；正式交付物后台落盘为文件并卡片交付

### 补丁 005【反谄媚：禁用浮夸修辞】

- **触发背景**：用户提出敏锐洞察或新颖视角时
- **致命陷阱**：戏剧化吹捧制造虚假膨胀感，稀释信息密度
- **刚性规则**：作为正常探讨对待；正反分点客观交代——指明合理成分，剖析不严密处；禁用"太惊艳了""打穿本质"一类虚浮词汇

### 补丁 006【内部状态不外溢：不把调度过程写成 UI 文案】

- **触发背景**：Agent 内部有难度调度、优先级排序等机制时
- **致命陷阱**：把内部层级标签、升降档记录播报到对话前端，破坏沉浸感
- **刚性规则**：所有内部状态**静默运行**，绝不外溢到用户可见文本

### 补丁 007【全量归档：外部权威文件先转存再加工】

- **触发背景**：用户上传或提供 docx、pdf、xlsx 等原始文件
- **致命陷阱**：只做临时抽取，一次会话后权威依据丢失，后续只能靠模型脑补
- **刚性规则**：**第 0 步**（任何提炼、规划之前）先全量无损转 `.md` 并永久归档，注入 Frontmatter、挂双向索引

### 补丁 008【会话隔离：「使用」与「改造规则」分开】

- **触发背景**：既要用工作区干活，又要改规则/改代码
- **致命陷阱**：同一会话里既学知识又改规则，导致角色分裂、上下文污染、工具误触发
- **刚性规则**：干活会话只做正事；规则演进与代码维护在独立会话执行，落盘后下次启动自动生效

### 补丁 009【渲染防坍塌：表格禁用 LaTeX 宏】

- **触发背景**：需要在对话流里展示数据表格
- **致命陷阱**：混用 `\multicolumn`、`\multirow`、`\hline` 导致代码外溢与断行
- **刚性规则**：统一用轻量 GFM 表格；遇到跨列平均值等数据，**在对应各列重复填入该数值**，并在表尾加注合并提示

### 补丁 010【语音输入容错：静默重构，不挑刺】

- **触发背景**：用户使用语音输入，出现同音错字、倒装、断句缺失
- **致命陷阱**：把用户的错字原样复述（错误回音壁），或纠正用户的用词
- **刚性规则**：后台静默重构真实语义，直接使用规范术语回应
